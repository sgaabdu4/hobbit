# Habitaker demo plan

Target length: 80 to 90 seconds. Record real app behavior. Do not include API keys, Apple account pages, ChatGPT account details, notifications or personal habit text.

1. **0–8 seconds:** “Habitaker turns a habit reminder into a short conversation with your own AI pet.” Show the pet choice screen.
2. **8–20 seconds:** Show “Create my pet”, a short fictional character description, and the generated preview. If cutting the generation wait, label the cut honestly. Choose the pet.
3. **20–30 seconds:** Use “Stretch for two minutes” and Gentle mode. Briefly show that stronger coaching is optional.
4. **30–48 seconds:** Tap “Call me in 15 seconds” and lock the iPhone. Show the real incoming call screen and answer it.
5. **48–70 seconds:** Open Habitaker if iOS leaves the system call screen visible. Have a short conversation. Show the speaking and listening states. Report completion only after doing the example action, or use a clearly labelled test habit.
6. **70–80 seconds:** Show completion saved on the phone and the undo control.
7. **80–90 seconds:** “Codex built the secure ChatGPT sign-in, native calling integration and tests. Live handles voice; Decisions handles intent and expressions; GPT Image 2.5 makes the pet.” Show the public repository URL once available.

Before recording, verify foreground two-way audio, then locked-screen call delivery. Device Hub screen sharing conflicts with microphone use on a physical iPhone, according to Apple's Device Hub documentation. Use a recording setup that leaves the microphone available. Keep this Mac awake on the same network while the local development server runs.

Do not describe the 15-second test control as a shipped daily scheduler. Do not claim ChatGPT pet-library sync or a full ChatGPT sprite export. The current custom-pet format has four expression states. The public README must match the final device-test results.
